Maintenance

RestartReboot the module. Settings are kept.
Recovery Mode To reach a module you can't open anymore (wrong WiFi settings, forgotten web password), without losing its settings.
  • Press the module's reset button several times in a row (3 times by default, each within 5 seconds).
  • The module then only opens its own WiFi network and answers at 192.168.4.1, without asking for the web password.
  • Fix the settings and save them: the module goes back to normal operation. A restart without saving does the same.
Reset configuration Erase all settings and restart with the default configuration.
